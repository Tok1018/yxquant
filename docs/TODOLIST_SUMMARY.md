## 项目概述

本项目是一个基于AI的智能量化交易分析系统，集成了多种AI模型（GPT、DeepSeek、Gemini、Qwen、Grok等），提供技术分析、策略优化、风险管理和交易信号生成等功能。

## 使用指南

### 快速开始
1. **环境准备**: Python 3.8+, 4GB+ 内存
2. **安装依赖**: `pip install -r requirements.txt`
3. **配置AI**: 编辑 `ai_config.json` 添加API密钥
4. **启动系统**: `python start.py`
5. **访问界面**: http://localhost:8000

### 开发环境
1. **克隆项目**: `git clone <repository>`
2. **创建虚拟环境**: `python -m venv venv`
3. **激活环境**: `source venv/bin/activate` (Linux/Mac)
4. **安装依赖**: `pip install -r requirements.txt`
5. **运行测试**: `python tests/run_tests.py`

### 生产部署
1. **Docker部署**: `docker-compose up -d`
2. **配置监控**: 设置Prometheus和Grafana
3. **配置日志**: 设置日志聚合和告警
4. **性能优化**: 根据负载调整配置参数
