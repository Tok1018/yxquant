## 版本说明

### 版本号格式
- **主版本号**: 不兼容的API修改
- **次版本号**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

### 更新类型
- **新增**: 新功能
- **改进**: 现有功能的改进
- **修复**: 问题修复
- **移除**: 功能移除
- **安全**: 安全性相关更新
- **性能**: 性能相关更新

### 贡献指南
1. 在相应的版本下添加更改
2. 使用清晰的描述说明更改内容
3. 按照重要性排序（新增 > 改进 > 修复）
4. 链接相关的Issue和Pull Request

### 发布流程
1. 更新版本号
2. 更新CHANGELOG.md
3. 创建Git标签
4. 发布到GitHub
5. 更新文档
